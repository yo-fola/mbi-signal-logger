# API Reference

Current backend: `server/server.js`  
Local development service: `http://localhost:3000`  
Example reverse-proxy prefix: `https://signal-logger.example.com/api/*`

## Endpoints

| Method | Route | Purpose |
|---|---|---|
| GET | `/api/health` | API/runtime health snapshot, including sequence state |
| GET | `/api/config` | Read runtime application configuration |
| PUT | `/api/config` | Replace/update runtime application configuration |
| GET | `/api/audit` | Read audit/activity records |
| GET | `/api/admin/audit` | Admin audit alias |
| POST | `/api/audit` | Record GUI/admin activity |
| POST | `/api/rf-estimate` | Server-authoritative RF estimate from station/GPS context |
| GET | `/api/incidents` | Field/engineer incident views |
| POST | `/api/incidents` | Create Field or Public incident; server assigns ID |
| PATCH | `/api/incidents/:id` | Update an incident |
| DELETE | `/api/incidents/:id` | Delete an incident |
| GET | `/api/public-incidents` | Public incident views |
| GET | `/api/analysis/incidents` | Combined Field/Public incident views |
| GET | `/api/summary` | Field incident summary |
| GET | `/api/analysis/summary` | Combined analytical summary |
| GET | `/api/incidents/export.csv` | Field incident CSV export |
| GET | `/api/analysis/incidents/export.csv` | Combined analysis CSV export |

## Incident create behavior

`POST /api/incidents` performs more than raw storage. Depending on the report source it may:

- assign a server-generated `INC` or `PUB` ID,
- check submission-key duplicates,
- validate/enrich GPS,
- determine station reference data,
- calculate distance,
- generate RF reference values,
- preserve measured engineer signal values where supplied,
- build observation scoring,
- persist to the correct JSON store,
- write audit activity.

## Compatibility

Older client-supplied IDs remain readable. New clients should rely on the server-generated identity flow.

## KML

KML export is generated by the Admin frontend from its filtered incident dataset rather than through a dedicated server KML endpoint.
